# Infrachrome

An Aerochrome-style infrared photo editor that runs entirely in the browser. Pick a photo, turn the foliage pink, add film grain and halation, then save the full-size result. Nothing is uploaded — all processing happens on your device.

## Live site

https://manuqwert1234.github.io/infocrome/

## Run locally

Open `index.html` in any modern browser. No build step needed.
